## 1. 게임 한 장 요약

조선 시대 마당놀이 **투호** — 화살을 던져 항아리에 넣습니다.

- 탭 2번: **각도** 멈추기 → **힘** 멈추기. 화살이 포물선으로 날아갑니다.
- 항아리에는 구멍이 **3개**: 가운데 **입구**, 그리고 양옆에 달린 **귀(耳)** 2개.
  가운데 정중앙은 **관(貫) ×2.5**, 좁은 귀는 **×2**, 그냥 들어가면 ×1.
- 한 단계 = 화살 5발. 목표 수만큼 넣으면 다음 단계로. **빗나간 화살은 땅에 꽂혀 남습니다.**
- 단계가 오를수록 항아리가 멀어지고, 입구가 좁아지고, 바람이 붑니다.

**플레이 1판 ≈ 3~10분, 1발 ≈ 4초.** 화면은 고정된 한 장면이고 카메라 이동이 없습니다.

## 3. ⚠️ 치명적 제약 3가지

### ① 실제 렌더 크기가 아주 작습니다

화면 375×812 기준 **실측값**입니다. 이보다 크게 그려서 축소하면 디테일이 뭉개집니다.

| 오브젝트 | 실제 화면 크기 |
|---|---|
| 항아리 | **66~102 × 78~122 px** |
| 날아가는 화살 | **42 × 12 px** |
| 꽂힌 화살 (보이는 부분) | 38 × 11 px |
| 사대(멍석) | 68 × 14 px |
| 바람 깃대 | 높이 136~180 px, 깃발 길이 28~54 px |
| 해/달 | 반지름 20~26 px (글로우 70) |
| 파워 게이지 | 308 × 20 px |
| UI 아이콘 버튼 | 38 × 38 px |
| 파티클 1개 | 반지름 2~5 px |

→ **@3x 가 실질 상한입니다.** 항아리는 306×366px 안에서 완결되어야 합니다.
→ **디테일보다 실루엣**. 1x로 축소해 보고 형태가 읽히는지 반드시 확인해 주세요.

### ② 항아리 입구·귀 비율은 '게임 판정 좌표'입니다

코드가 입구 폭과 귀 위치를 **숫자로 직접 계산해 적중 판정**에 씁니다.
그림의 비율이 다르면 **눈에 보이는 구멍과 실제로 들어가는 자리가 어긋납니다.** (게임이 망가집니다)

```
귀 폭      = 입구 폭 × 0.30
귀 중심    = 입구 중심에서 ± 입구 폭 × 0.75
귀 외곽    = 입구 중심에서 ± 입구 폭 × 0.90
입구 타원 세로반경 = 입구 폭 × 0.18
귀   타원 세로반경 = 귀 폭   × 0.24
귀 높이    = 귀 폭 × 1.6
```

좋은 소식: **이 비율은 전 단계에서 고정**입니다. 즉 **림(입구)+귀 어셈블리는 1장으로 끝나고, 균등 확대/축소만** 하면 됩니다. → 상세 치수는 [pot-spec.svg](pot-spec.svg)

### ③ 몸통은 단계마다 세로로 2.4배까지 늘어납니다

| 단계 | 몸통 폭 | 높이 | 높이/폭 |
|---|---|---|---|
| 1 | 102 | 78 | **0.76** |
| 10 | 84 | 92 | 1.10 |
| 20 | 66 | 108 | 1.64 |
| 30+ | 66 | 122 | **1.85** |

단계가 오르면 항아리는 **좁고 길어집니다** (멀어지고 어려워지는 연출). 단일 비트맵을 세로로 늘리면 띠 장식과 굽이 함께 늘어나 깨집니다.

→ **그래서 벡터 마스터(SVG 또는 AI)가 필수 납품물입니다.** 래스터 LOD는 개발이 벡터에서 뽑습니다.
(원하시면 아래 4개 비율로 직접 납품해 주셔도 됩니다: 높이/폭 = **0.85 / 1.10 / 1.45 / 1.75**)

## 6. 에셋별 상세 스펙

### 6-1. 항아리 ★ 최우선

**형태**: 전통 옹기 투호 항아리. 정면 **정투상**(透視 없음). 넓은 배, 좁은 목, 평평하게 열린 입구,
그리고 목 좌우에 **짧은 원통형 귀 2개** — 귀도 위가 뚫려 있어 화살이 들어갑니다.

- 입구와 귀 2개는 **속이 비어 보이는 검은 구멍**이어야 합니다 (화살이 들어가는 곳임이 즉시 읽혀야 함)
- 몸통 중앙에 **음각 띠 장식 1줄** (y = 높이의 50%, 폭 = 몸통폭 ±42%) — **별도 레이어**
- 굽(바닥) 폭 = 몸통 폭 × 0.60
- 바닥에 **접지 그림자** 타원 (몸통폭 × 0.84, 높이 14px @1x) — 별도 레이어
- 치수 전체: **[pot-spec.svg](pot-spec.svg) 준수**

**레이어 분리 요구** (벡터 마스터):
```
pot-master.svg
├─ shadow        접지 그림자
├─ ear-L         왼쪽 귀 (몸통 뒤에 깔림)
├─ ear-R         오른쪽 귀
├─ body          몸통 (단독으로 세로 변형 가능해야 함)
├─ band          띠 장식
├─ rim           입구 타원 + 림 립
└─ rim-notch     림 좌우 끝 하이라이트 2점
```
> 귀는 **몸통보다 뒤**에 그려집니다(코드 순서 동일). 귀가 몸통에 가려지는 부분까지 그려 주세요.

**변주 3종**: 기본 / 황금(색만) / 야간(쿨 림라이트 오버레이). 형태는 완전히 동일해야 합니다.

### 6-2. 화살

전통 투호 화살 — 전쟁 화살이 아닙니다. **대나무 대, 짧고 뭉툭한 촉, 흰 깃**.

- `arrow.png` — 완전 **수평, 우향**. 길이:두께 ≈ 20:1.
  **앵커(회전 중심) = 이미지 가로 62% 지점, 세로 중앙** (코드가 -26 ~ +16 범위로 그리므로)
- `arrow-stuck.png` — 꼬리 절반만. 촉은 프레임 아래로 빠져 안 보임. 자연스러운 8° 기울기.
  **앵커 = 이미지 하단 중앙**
- 관(貫) 적중 전용으로 **깃이 금색**인 변주 1종 추가 (`arrow-gold-stuck.png`)

### 6-3. 배경 3층

지평선은 화면 **높이의 78%** 지점에 고정됩니다. 각 레이어가 이 선을 기준으로 맞물려야 합니다.

- `bg-sky.png` — 해 위치: 가로 78%, 세로(지평선 기준) 28% 지점. 구름 3줄, 매우 저대비.
- `bg-hills.png` — 산 능선 2겹 실루엣. **밑변이 완벽히 수평**, 가로 심리스.
- `bg-ground.png` — 다진 흙 마당. 상단 가장자리에 따뜻한 하이라이트 1줄. 가로 심리스.
  잔돌·갈퀴 자국 정도의 저대비 텍스처.

> 구름은 **바람 방향으로 흐릅니다**(코드에서 스크롤). 세로 타일링은 불필요, 가로만.

### 6-4. 소품

- `mat.png` — 짚 멍석을 바닥에 깐 모습. 낮은 정면 시점, 모서리 약간 둥글게, 접지 그림자.
- `windpole.png` — 가는 나무 장대 + 둥근 꼭지. 깃발 **없이**.
- `windflag.png` — 삼각 깃발 **단독, 중립 흰색**. 코드가 색을 바꾸고 펄럭임을 변형합니다.
  **앵커 = 좌측 상단** (장대에 매달리는 점).
  바람이 없을 때는 축 처진 상태를 코드가 따로 그립니다.

### 6-5. 이펙트

- `fx-burst.png` — 2×2 시트 4프레임: 밝은 코어 → 방사 파편 → 확산 → 소멸. 각 프레임 셀 중앙 정렬, 셀 크기 동일.
- `fx-dust.png` — 흙먼지 1장. 아래가 진하고 가장자리로 투명하게.
- `fx-slowmo.png` — "한 끗" 슬로우모션 전면 오버레이. **중앙 60%는 완전 투명 필수.**

### 6-6. UI

- `ui-pill.png` / `ui-btn.png` — **9-slice 전제**. 각 변의 가운데 50%는 늘어나도 괜찮게 **평평하게** 유지.
  9-slice 분할선 위치를 별도 텍스트나 가이드 레이어로 표기해 주세요.
- `ui-icons.png` — 가로 4칸 등분. **단색 `#ffe6b0`**, 다른 색 금지. 24px에서 읽히게 굵직하게.
- 버튼은 두께감 있는 모바일 게임 버튼: 윗면 `#ffcf5c` + 하단 하드 베벨 6px `#b5831f`, 라운드 16px.
- 전통 문양(단청 구름무늬)은 **모서리에 아주 작게만**. 24px에서 노이즈가 되면 안 됩니다.

### 6-7. 앱 아이콘 / 스토어

- `appicon.png` 1024² — 항아리 + **입구로 떨어지는 화살 1발**을 림 바로 위에서 포착, 금색 스파크.
  **48px에서도 읽히는 강한 실루엣**. 텍스트/테두리/라운드 마스크 **미포함**.
- `feature.png` 1024×500 — 좌측 한복 실루엣(던진 직후), 우측 항아리(화살 3발 꽂힘), 중앙에 점선 궤적.
  **우측 상단 30%는 타이틀 오버레이용으로 비워 주세요.** 텍스트 미포함.

- 항아리 = 가로 53%(1단계) ~ 80%(20단계+)
- 상단 HUD 4칩 + 화살통/목표 1줄 + 바람 1줄 + 변주 1줄 → **상단 180px는 UI 영역**
  → 배경의 중요한 요소를 이 안에 두지 마세요
- 하단: 힌트 텍스트 / 파워 게이지(하단 62px) → **하단 120px도 UI 영역**
- `env(safe-area-inset-*)` 적용. 노치 47px / 하단 34px 가정
- 네이티브 배너 광고가 켜지면 **하단 64px이 추가로 가려집니다**

## 8. 납품 규격

### 포맷

- **벡터**: SVG (권장) 또는 AI. 레이어명은 위 트리 그대로. 폰트는 모두 패스화.
- **래스터**: PNG-24 + 알파. 프리멀티플라이드 알파 **아님**. sRGB. 메타데이터 제거.
- **배수**: @3x 로 1종만 납품하면 됩니다 (개발이 @1x/@2x 생성).
  단 `appicon`, `feature`는 명시 크기 그대로.

### 네이밍 / 폴더

```
tuho-art/
├─ vector/      pot-master.svg, pot-gold-master.svg, archer-master.svg
├─ sprite/      pot-rim-ears.png, pot-body-lod1..4.png, arrow.png, ...
├─ bg/          bg-sky.png, bg-hills.png, bg-ground.png
├─ ui/          ui-pill.png, ui-btn.png, ui-icons.png
├─ fx/          fx-burst.png, fx-dust.png, fx-slowmo.png
├─ store/       appicon.png, feature.png
└─ ANCHORS.md   에셋별 앵커 좌표 / 9-slice 분할선
```

- 파일명 **전부 영문 소문자 + 하이픈**. 공백·한글·대문자 금지.
- `ANCHORS.md`에 앵커(회전/배치 기준점)를 **px 좌표**로 명기해 주세요. 이게 없으면 조립이 안 됩니다.

### 스프라이트 시트

- 셀 크기 **균등**, 셀 중앙 정렬, 프레임 간 **2px 이상 투명 패딩**(블리딩 방지)
- 시트 1장에 1개 애니메이션만
