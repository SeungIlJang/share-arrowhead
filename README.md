# 🏹 모두의 화살촉 (Arrowhead)

화살을 던져 항아리에 넣는 한국 전통놀이 **투호(投壺)** 기반 캐주얼 게임.
전통놀이 시리즈 2탄.

## 플레이

- **① 탭 = 각도** — 궤적의 *모양*을 고릅니다 (높게 띄울지, 낮게 쏠지)
- **② 탭 = 힘** — 흰 점선(이상 궤적)에 맞춥니다
- 한 단계 = **화살 5발**. 목표 수만큼 넣으면 다음 단계로.

### 과녁은 3구역

```
   ◣귀◢   ╭─ 입구 ─╮   ◣귀◢
    ×2       관 ×2.5      ×2
           들어감 ×1
```

- **관(貫)** 정중앙 ×2.5 · **귀(耳)** 좌우 구멍 ×2 · **들어감** ×1
- **한 끗** — 턱에 걸렸다가 쏙 들어가면 ×1.5
- 연속 성공 배수 최대 ×2, 전관(5발 전부) 보너스 ×2

### 핵심 트레이드오프

| | 유효 입구 | 바람 밀림 |
|---|---|---|
| 낮게(평사) | 좁다 (16px) | 적다 (33px) |
| 높게(고사) | 넓다 (33px) | 많다 (56px) |

바람은 조준선에 **반영되지 않습니다.** 깃발과 **땅에 꽂힌 지난 화살**을 읽어 보정하세요.

### 단계 변주 (4단계부터, 15단계부터 2개 중첩)

💨 강풍 · 🏺 흔들 항아리 · 🎯 좁은 입구 · 🌙 밤 · 🌫 안개 · 🥇 황금 항아리(보상)

### 📅 오늘의 도전

날짜를 시드로 고정해 **그날은 누구나 똑같은 판**(바람·변주 순서)을 받습니다.

- 시도 횟수 제한 없음, **그날의 최고 점수**가 기록됩니다
- 연속 참여일(🔥)을 셉니다
- 판이 같아야 비교가 되므로 **광고 이어하기는 막혀 있습니다**
- 결과를 **이미지 카드**(1080×1350)로 공유할 수 있습니다 — 아래 참조

연출용 난수(파티클·화면 흔들림·꽂힌 각도)는 시드를 쓰지 않습니다 — 판의 내용과 무관하고,
시드를 소모하면 재현이 깨지기 때문입니다.

### 📤 결과 공유 카드

게임오버에서 **1080×1350(4:5)** 이미지 카드를 만들어 공유합니다. 두 모드 모두 지원합니다.

게임과 같은 팔레트·같은 항아리로 그려서 카드 한 장만 봐도 무슨 게임인지 읽히게 했고,
**이번 판에 넣은 화살이 항아리에 꽂힌 모습**으로 나타납니다(관 적중은 금색 깃).
점수·도달 단계·구역별 적중(관/귀/한 끗)·연속일·접속 주소가 들어갑니다.

공유는 단계적으로 떨어집니다: `navigator.share(files)` → 이미지 다운로드 → 문구 복사.

## 기술

- 순수 HTML5 Canvas + WebAudio, **외부 의존성 없음** (단일 파일 `index.html`)
- 세로 모바일 전용 (가로 전환 시 안내 화면)
- 업적 8종 / 기록은 `localStorage`
- AdMob 연동 (Capacitor 네이티브에서만 동작). **실 광고 단위 적용됨** —
  개발 중에는 `AD_USE_TEST = true` 로 되돌려 테스트 단위를 쓸 것 (실광고 클릭 시 계정 정지 위험)
- OTA 라이브: https://seungiljang.github.io/games/tuho.html

## 검증

DOM·캔버스를 스텁해 게임 스크립트를 그대로 구동하는 헤드리스 하네스로
물리·판정·**난이도 램프**·손감각 불변식·**보상 계층**·기기 무관 난이도·
일일 도전 재현성·공유 카드 레이아웃·**광고 중단 스위치**를 **137개 항목** 자동 검증합니다.
변주가 섞이는 측정은 모두 `plain(s)`(변주 끔)를 거치므로 **실행마다 같은 결과**가 나옵니다.

> ⚠️ **광고는 현재 전면 중단** 상태입니다 (`ADS_ENABLED=false`, AdMob 계정 정지
> 2026-11-03 ~ 12-02). 이 스위치는 **이 파일(`index.html`)이 원본**이고 배포본
> `games/tuho.html` 은 복사본입니다. 예전에는 배포본에만 스위치가 있어 소스를
> 덮어쓰면 광고가 되살아났습니다. 하네스 §0 이 꺼짐을 막아 줍니다.

```bash
node tools/harness.js index.html
```

항아리 아트는 **게임 적중 판정 좌표와 직결**되므로 별도 검증기가 있습니다.
투명 PNG를 픽셀 실측해 귀 구멍 폭·오프셋·외곽·림 높이가 규격 안에 드는지 확인합니다.

```bash
node tools/check-pot-art.mjs <항아리.png>
```

## 상태

**v0.7 — 누각 등반 · 손으로 던지기.** 게임이 가로 한 판에서 **세로 등반**으로 바뀌었습니다.
누각을 한 층씩 오르고 발사대가 좌↔우로 교대합니다.

- **조작이 바뀌었습니다.** 당겼다 놓는 조준이 아니라 **휘두른 속도와 방향이 그대로 던지기**가
  됩니다. 휘두름→속도 매핑은 층과 무관한 절대값이라 손감각이 쌓입니다.
- **1층 시범 궤적** — 한 발도 못 넣어 본 손에게만 들어가는 궤적을 점선으로 보여 주고,
  유령 화살이 실제 체공 시간대로 지나가 "이 정도 세기"를 알려 줍니다. 한 발 넣으면 사라집니다.
- **난이도 램프 3.8배** — 전에는 18층부터 난이도가 멈춰 있었습니다(허용폭 1층 22% → 30층 5.5%).
- 아트 8장(누각 기둥·발판·하늘·구름·별·링·조준점·손)이 **data URL 로 심겨** 단일 파일입니다.

v0.6 기기 무관 난이도, v0.5 공유 이미지 카드, v0.4 일일 도전, v0.3 3구역 과녁·5발 단계제.

**보상 계층 (v0.7)** — 런을 넘어 쌓이는 것이 없어서 5판쯤 하면 열 것이 없었습니다.

- **손감각 등급** — 던질 때마다의 세기 오차를 최근 50발까지 누적해 등급을 매깁니다.
  임계값은 실측한 층별 허용폭의 반폭에서 가져왔으므로 등급이 곧 **"이 손이면 몇 층까지"**
  입니다(신선 ≤2.8% = 30층급 … 초보 ≤10.5% = 1층급). **기록을 못 깬 판에서도 올라갑니다.**
- **누각 이정표** — 5층마다 처마·종루·단청·구름다리·풍경·상륜. HUD에 "다음 종루까지 3층",
  최고 기록이 더 가까우면 "최고 기록까지 2층"을 먼저 보여줍니다.
- **자기 기록 돌파** — 판 중에 최고 층을 넘는 순간 알립니다(첫 판에는 띄우지 않습니다).
- **업적 8 → 16** — 후반·숙련 쪽으로.

**다음**: 점수·최고점·업적 저장 검사를 새 입력 기준으로 다시 쓰기 (v0.7 승격 때 남은 빈칸).

### 아트 교체 방법

`assets/` 의 PNG 를 바꾸고 다시 심습니다. 여러 번 돌려도 결과가 같습니다(멱등).

```bash
node tools/inline-assets.mjs
```

키 순서는 [assets/manifest.json](assets/manifest.json) 이 정합니다. 편집용 사본을 따로
두지 않는 이유는 그 둘이 갈라지는 사고를 이 프로젝트에서 이미 겪었기 때문입니다.
