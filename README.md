# 🏹 모두의 화살촉 (Arrowhead)

화살을 던져 항아리에 넣는 한국 전통놀이(투호) 기반 캐주얼 게임.
전통놀이 시리즈 2탄.

## 플레이
- **① 탭** = 각도 멈추기 → **② 탭** = 힘 멈추기
- 포물선으로 날아가 **항아리 입구**에 들어가면 성공 (한가운데 = 완벽 ×2)
- 바람·거리를 읽어 맞히기. 단계가 오를수록 멀고 좁고 바람이 세집니다.

## 기술
- 순수 HTML5 Canvas + WebAudio, 외부 의존성 없음 (단일 파일 `index.html`)
- 세로 모바일 전용
- OTA 라이브: https://seungiljang.github.io/games/tuho.html

## 상태
MVP (v0.2) — 재미 검증 단계. 도감·강화·랭킹·대결·앱 패키징 예정.
