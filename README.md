# 🏹 모두의 화살촉 (Arrowhead)

화살을 던져 항아리에 넣는 한국 전통놀이 **투호(投壺)** 기반 캐주얼 게임.
전통놀이 시리즈 2탄.

## 플레이

- **① 탭 = 각도** — 궤적의 *모양*을 고릅니다 (높게 띄울지, 낮게 쏠지)
- **② 탭 = 힘** — 흰 점선(이상 궤적)에 맞춥니다
- 한 단계 = **화살 5발**. 목표 수만큼 넣으면 다음 단계로.

### 과녁은 3구역

```
   ◣귀◢   ╭─ 입구 ─╮   ◣귀◢
    ×2       관 ×2.5      ×2
           들어감 ×1
```

- **관(貫)** 정중앙 ×2.5 · **귀(耳)** 좌우 구멍 ×2 · **들어감** ×1
- **한 끗** — 턱에 걸렸다가 쏙 들어가면 ×1.5
- 연속 성공 배수 최대 ×2, 전관(5발 전부) 보너스 ×2

### 핵심 트레이드오프

| | 유효 입구 | 바람 밀림 |
|---|---|---|
| 낮게(평사) | 좁다 (16px) | 적다 (33px) |
| 높게(고사) | 넓다 (33px) | 많다 (56px) |

바람은 조준선에 **반영되지 않습니다.** 깃발과 **땅에 꽂힌 지난 화살**을 읽어 보정하세요.

### 단계 변주 (4단계부터, 15단계부터 2개 중첩)

💨 강풍 · 🏺 흔들 항아리 · 🎯 좁은 입구 · 🌙 밤 · 🌫 안개 · 🥇 황금 항아리(보상)

## 기술

- 순수 HTML5 Canvas + WebAudio, **외부 의존성 없음** (단일 파일 `index.html`)
- 세로 모바일 전용 (가로 전환 시 안내 화면)
- 업적 8종 / 기록은 `localStorage`
- AdMob 훅 내장 (Capacitor 네이티브에서만 동작, 현재 **테스트 광고 단위**)
- OTA 라이브: https://seungiljang.github.io/games/tuho.html

## 검증

DOM·캔버스를 스텁해 게임 스크립트를 그대로 구동하는 헤드리스 하네스로
물리·판정·난이도 곡선·화면 비율을 **79개 항목** 자동 검증합니다.

```bash
node tools/harness.js index.html
```

항아리 아트는 **게임 적중 판정 좌표와 직결**되므로 별도 검증기가 있습니다.
투명 PNG를 픽셀 실측해 귀 구멍 폭·오프셋·외곽·림 높이가 규격 안에 드는지 확인합니다.

```bash
node tools/check-pot-art.mjs <항아리.png>
```
